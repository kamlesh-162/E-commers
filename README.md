# 🛒 Amazon E-Commerce Website Clone

A responsive e-commerce website inspired by Amazon, built using HTML, CSS, and Vanilla JavaScript. This project was created to practice frontend development, DOM manipulation, asynchronous JavaScript, and API integration.

## ✨ Features

- **Product Listing:** Display products with images, prices, and ratings.
- **Checkout Page:** View order summary and payment details.
- **Dynamic Product Loading:** Retrieve product information using the Fetch API.
- **Interactive UI:** Handle user actions using DOM manipulation and event listeners.
- **Modular JavaScript:** Organize code using ES modules and reusable functions.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- JavaScript Modules (`import` / `export`)
- Promises and `async/await`
- Fetch API and REST APIs
- Local Storage
- Day.js for date handling
- Git and GitHub

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kamlesh-162/E-commers.git
```

### 2. Open the project

Open the `javascript-amazon-project` folder in Visual Studio Code.

### 3. Run the website

Use the **Live Server** extension in VS Code to launch the HTML pages.

For example, open `index.html` using Live Server to view the product page.
